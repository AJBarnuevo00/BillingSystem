# BillingSystem
A C# Windows Forms application for billing and customer management.

## Feautres
* **LoginForm:** Secure user authentication.
* **AddCustomerForm:** Input and save new customer data.
* **CustomerListForm:** view and manage customer records.

## Requirements
* Visual Studio
* .NET Framework / .NET Runtime
 
## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Open `BillingSystem.sln` in Visual Studio.
3. Press **F5** to run the application.
